# 💫 About Me:
I'm Jaymark Vicente, an aspiring Java Backend Developer and 2nd-year BSIT student at Occidental Mindoro State University – Sablayan Campus.<br>My main focus is Java and Spring Boot backend development. I also work with Vue.js for frontend development as a supporting skill, mainly when I need to build and integrate the frontend for my backend projects.<br>I learn by building real projects, solving problems, debugging, and understanding how things work under the hood.<br>My goal is to build useful software that can solve real-world problems and help people in the future.<br>I currently build web applications using only my phone because I don't have a laptop yet. Despite the limited resources, I continue learning and building with what I have.<br>Outside programming, I'm also a drummer and musician in the band Mudyako.
